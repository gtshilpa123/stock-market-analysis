# 📈 Stock Market Dashboard

Built an interactive \textbf{stock market dashboard} using JavaScript and the Canvas API to visualize stock price trends across multiple time ranges (1M, 3M, 1Y, 5Y).
Integrated \textbf{REST APIs} to fetch and display real-time stock data, including price history, summaries, and key financial metrics.
Implemented dynamic features such as hover tooltips, responsive charts, and stock selection, enhancing user interactivity and experience.
Structured the application using \textbf{modular ES6 JavaScript}, improving code organization, maintainability, and scalability.
Designed a clean and responsive UI with efficient DOM manipulation and event handling for seamless performance.

## 🚀 Features

- Interactive stock chart using HTML Canvas
- Multiple time ranges (1M, 3M, 1Y, 5Y)
- Dynamic tooltip with price tracking
- Stock summary and statistics
- Responsive UI design

## 🛠 Tech Stack

- HTML, CSS, JavaScript (ES6)
- Canvas API
- REST APIs
